## 🌟 Key Features

- 🎨 **Khmer Royal & Traditional Gold UI**: Crafted with a regal obsidian & antique gold dark theme and warm ivory parchment light theme, featuring subtle traditional diamond lattice accents.
- 🌐 **Bilingual Support (EN / KH)**: Dynamic language switcher supporting **English** and **Khmer (ភាសាខ្មែរ)** with `Khmer OS Battambang` and `Khmer OS Muol Light` (`Moul`) typography.
- 🌓 **Dark & Light Mode**: Persistent theme switcher with smooth transitions and CSS custom properties.
- ⚡ **Native Smooth Scroll & Scroll Spy**: Lightweight `IntersectionObserver` navigation tracking for zero-jank scrolling across sections.
- 📄 **Interactive CV Viewer & PDF Export** *(Local Dev)*: Client-side A4 resume preview and single-page PDF export in English or Khmer.
- 💼 **Featured Project Showcase**: Showcasing **HR & Payroll System**, **Banking System**, **School Management System**, and more with live demo & GitHub repository links.

## 🛠️ Tech Stack

### Frontend & UI
- **Framework**: [React.js 19](https://react.dev/) (Functional Components & Hooks)
- **Bundler**: [Vite 8](https://vitejs.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) & Custom Brand SVGs
- **Styling**: CSS Modules, CSS Custom Variables, Responsive Grid & Flexbox
- **Fonts**: Plus Jakarta Sans, Playfair Display, Cormorant Garamond, Battambang, Moul (Google Fonts)
- **PDF Generation**: [html2pdf.js](https://ekoopmans.github.io/html2pdf.js/) & [jsPDF](https://parall.ax/products/jspdf)
- **Deployment**: [Cloudflare Workers](https://workers.cloudflare.com/) (Auto-deploy from `main`)

## 🚀 Getting Started

### Prerequisites
Make sure you have the following installed on your machine:
- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### 1. Clone the Repository
```bash
git clone https://github.com/YimLemeng/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
